# TechVision AI — Texnik Qurilmalarni Tanuvchi Multimediya Tizimi

**Fan:** Multimediya Texnologiyalari (Multimedia Technology)  
**Loyiha turi:** Universitet amaliy / laboratoriya / kurs loyihasi  
**Dastur maqsadi:** Har qanday texnik yoki elektron qurilmani kamera orqali ko'rsatganda yoki rasmini yuklaganda uni tanib, qurilmaning:
1. **Nomi** (O'zbek, Rus va Ingliz tillarida)
2. **Vazifasi va nima qilishi** (To'liq tushuntirish va ishlash prinsipi)
3. **Tuzilishi va tarkibiy qismlari** (Plata elementlari, chiplar, portlar, datchiklar anatomiyasi)
4. **Multimediya audio diktori** (O'zbek tilida ovoz chiqarib aytib berish - Text-to-Speech)
5. **Texnik xarakteristikalari va qo'llanish sohalari** haqida to'liq hisobot berish.

---

## 🌟 Loyihadagi Multimediya Unsurlari (Multimedia Elements)
Ushbu loyiha "Multimediya texnologiyalari" fanining 5 ta asosiy komponentini to'liq qamrab olgan:
- **Matn (Text):** Qurilma nomi, ishlash prinsiplari, texnik ko'rsatkichlar jadvali.
- **Grafika (Graphics & Visual UI):** Cyberpunk / Glassmorphism futuristik interfeys, 3D reticle nishoni, animatsiyalar.
- **Video / Kamera (Live Stream):** Foydalanuvchi veb-kamerasidan real vaqtda video oqimini qabul qilish va kadrni ushlash.
- **Audio (Sound & Speech Synthesis):**
  - Sun'iy intellekt diktori (Speech Synthesis) orqali qurilma haqidagi ma'lumotni ovoz bilan o'qib berish.
  - Web Audio API orqali sintez qilingan dinamik ovoz effektlari (skaner signali, muvaffaqiyat akkordi, tugma tovushlari).
- **Interaktivlik (Interactivity):** Kamera boshqaruvi, Drag & Drop rasm yuklash, qurilmalar katalogini qidirish, interaktiv bilimni tekshirish viktorinasi (Quiz), hisobotni PDF/chop etish.

## 🚀 Qanday Ishga Tushiriladi?

### 1-Usul: Eng tezkor va qulay (Web-versiya, Hech narsa o'rnatish shart emas!)
1. Loyiha papkasidagi **`start_app.bat`** faylini ikki marta bosing.
2. Dastur darhol standart brauzeringizda (Chrome, Opera, Edge) ochiladi.
3. Kamera tugmasini bosib qurilmani ko'rsatishingiz, rasmini yuklashingiz yoki namunaviy qurilmalarni sinab ko'rishingiz mumkin!

### 2-Usul: Python Desktop versiyasi (Agar Python talab qilinsa)
1. Python o'rnatilganligiga ishonch hosil qiling.
2. `python_version` papkasiga o'ting:
   ```bash
   cd python_version
   pip install -r requirements.txt
   python main.py
   ```
   yoki `run_python.bat` faylini bosing.

## 🧠 Qamrab Olingan Asosiy Qurilmalar Bazasi
Dastur quyidagi texnik va elektron komponentlarni chuqur tahlil qila oladi:
- **Kompyuter apparaturasi:** Ona plata (Motherboard), Markaziy protsessor (CPU), Operativ xotira (RAM), Videokarta (GPU), SSD/HDD disklar, Quvvat bloki (PSU).
- **Mikrokontroller va robototexnika:** Arduino Uno, Raspberry Pi 4, ESP32 Wi-Fi & Bluetooth, L298N dvigatel drayveri.
- **O'lchov va laboratoriya asboblari:** Raqamli multimetr (Tester), Raqamli ossillograf, Kavsharlagich (Payalnik).
- **Radio-detallar va elektronika:** Rezistorlar, Kondensatorlar, Tranzistorlar, Diodlar, Induktorlar.
- **Datchiklar va IoT:** HC-SR04 ultratovush masofa sensori, PIR datchigi, Wi-Fi routerlar.
